# Day 01 — Первый API-запрос

## Суть эксперимента

Интерактивная консольная программа отправляет сообщение пользователя через
OpenAI Responses API и выводит ответ модели. Каждый запрос независим:
история диалога не передаётся.

## Что проверяет

Базовый цикл взаимодействия с моделью: ввод сообщения → запрос к API →
получение и отображение ответа.
