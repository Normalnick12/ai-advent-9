# Day 26 — Локальная LLM

## Суть эксперимента

Знакомство с локальной Qwen через Ollama на Windows. Модель запускается на своём
компьютере и отвечает на вопросы о Kotlin и Android через терминал и HTTP API.

## Что проверяет

- Запуск модели и обращение к ней двумя способами.
- Полезность первых объяснений кода.
- Ограничения контекста и достоверности ответов.

## Результаты

Локальный запуск через CLI и HTTP проверен. Модель отвечает на вопросы о коде,
но её объяснения требуют проверки разработчиком: убедительный ответ может
содержать неверные предположения.

Это вводный эксперимент без отдельной программы в репозитории. Для запуска
нужны Ollama и установленная локальная модель; дальнейшая работа оформлена
в [помощнике Day 27](../day-27-local-architecture-assistant/README.md).
