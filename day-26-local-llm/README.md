# Day 26 — Локальная LLM

## Суть эксперимента

Ollama установлена и проверена на домашнем Windows-ПК. Локальная Qwen запускалась
через CLI и HTTP; первые вопросы относились к Kotlin и Android. Вычисления
выполнялись на своей машине, без облачного API модели.

Это документационный итог учебного этапа, подтверждённый пользователем при
завершении Week 6. Отдельная реализация Day 26 в репозитории отсутствует.
Точные времена, digest и полный протокол этого дня не сохранены здесь, поэтому
численные результаты не заявляются.

## Что проверяет

- Возможность обращаться к установленной локальной модели из терминала и по HTTP.
- Пригодность первых объяснений Kotlin/Android для ручной проверки разработчиком.
- Ограничения локальной модели: доступный контекст, ресурсы и достоверность ответа.

## Результаты

Запуск на Windows и оба способа обращения подтверждены пользователем. Модель
может отвечать на вопросы о коде, но убедительная формулировка не гарантирует
правильность. Контекст ограничен переданными данными; отсутствующие реализации
зависимостей нельзя восстановить из одного вызова. Увеличение контекста и размера
модели требует ресурсов, а качество необходимо оценивать отдельно от успешного
HTTP-запроса. Универсальная пригодность для Android-разработки не доказана.

Нужны установленная Ollama и заранее загруженная локальная модель. Безопасные
команды просмотра, не запускающие генерацию: `ollama --version`, `ollama list`,
`ollama ps`. В финализации недели новые обращения к модели не выполнялись.
Mac M1 в этом этапе не проверялся. OpenSpec change для Day 26 отсутствует.
