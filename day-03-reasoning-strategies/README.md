# Day 03 — Сравнение стратегий рассуждения

## Суть эксперимента

Четыре стратегии решают одну задачу: выбрать из восьми фич набор с максимальной
ценностью при бюджете 15 story points, учитывая зависимости и несовместимость.

| Стратегия | Подход | API-вызовы |
|---|---|---:|
| DIRECT | Прямой ответ | 1 |
| STEP_BY_STEP | Инструкция решить задачу по шагам | 1 |
| META_PROMPT | Сначала создать инструкцию, затем решить задачу с ней | 2 |
| EXPERT_PANEL | Смоделировать обсуждение аналитика, инженера и критика | 1 |

EXPERT_PANEL использует одну ролевую инструкцию. Модель, reasoning effort,
лимит токенов и формат финального ответа одинаковы для всех стратегий.

## Что проверяет

Влияет ли способ постановки задачи на правильность ответа, расход токенов,
время и число вызовов. Для META_PROMPT учитываются затраты обоих вызовов.

Решение проверяется алгоритмом независимо от объяснения модели.
Полный перебор даёт единственный оптимум: **A + C + F + G**,
стоимость **15**, ценность **29**.
[Полное условие задачи](../openspec/specs/reasoning-strategy-evaluation/spec.md).

## Результаты

Численные результаты не зафиксированы, поэтому победитель не определён.
Сначала сравнивается правильность решений, затем затраты на их получение:
более сложная инструкция сама по себе не доказывает улучшение результата.
