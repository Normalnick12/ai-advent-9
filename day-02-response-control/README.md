# Day 02 — Управление ответом

## Суть эксперимента

Сравнение свободного ответа модели и ответа с ограничениями на одном запросе.
Режим COMPARE показывает оба ответа, статус завершения и расход токенов.

## Что проверяет

Как отдельные ограничения влияют на формат, длину и завершение ответа.
Для сравнения меняется только один из переключателей:

| Контроль | Механизм |
|---|---|
| FORMAT | Structured Outputs: строгая JSON Schema рецепта |
| LENGTH | Ограничение выходных токенов через max_output_tokens |
| STOP | Инструкция завершить ответ сразу после результата |

## Что важно при оценке

Structured Outputs задаёт проверяемую структуру ответа. Лимит токенов может
прервать ответ со статусом incomplete. Инструкция завершения выражает пожелание
модели: это не API-параметр stop и не жёсткое ограничение длины.
