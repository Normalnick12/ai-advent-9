# Поиск контекста

## Область применения

Документ описывает только локальный поиск по подготовленному индексу.
Он не устанавливает SLA и не доказывает качество ответа модели.

## Ранжирование

Функция search сортирует результаты по возрастанию cosine similarity:
сначала возвращаются наименее похожие фрагменты.

## Потребители

Ассистент разработчика и ассистент поддержки используют одинаковый top-k = 5.
Ассистент разработчика просто возвращает эти пять фрагментов без дополнений.
Поддержка формирует embedding только из вопроса пользователя и не добавляет
технические наблюдения обращения.

## Источники

Описание требует проверки по исходникам.
