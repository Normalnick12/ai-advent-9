# Day 28 — Local Android Architecture Assistant + RAG

## Суть эксперимента

Помощник Day 27 дополнен постоянной базой знаний в Markdown. Перед ответом
он ищет подходящие фрагменты документации и передаёт их модели вместе с Kotlin.
SQLite хранит индекс для текстового и векторного поиска; исходники остаются
во временном Workspace и не индексируются.

## Что проверяет

- Поиск правил, связанных с вопросом и выбранным кодом.
- Ответы со ссылками на Kotlin и точными цитатами документации.
- Различие объяснений одного файла без документации и с RAG.

## Результаты

Индексация, оба режима поиска и проверка актуальности документов работают.
Векторный поиск находил правила при перефразированном вопросе; покрытие
документации оставалось неполным.

**Улучшение качества объяснений через RAG не подтверждено:** смысловое
сравнение с вариантом без документации не завершено. Наличие точной цитаты
само по себе не доказывает правильность применения правила. Mac не проверялся.

Настройка и запуск — в [руководстве общей утилиты](../day-27-local-architecture-assistant/docs/usage.md#knowledge-и-rag-расширение-day-28).
