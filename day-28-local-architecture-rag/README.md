# Day 28 — Local Android Architecture Assistant + RAG

## Суть эксперимента

Существующий CLI Day 27 расширен постоянной Markdown Knowledge, SQLite-индексом,
локальными embeddings Ollama и двумя режимами поиска: vector и FTS5 text.
Временный Kotlin Workspace не индексируется. Ответ разделяет наблюдения по коду,
правила документации, их применение, предположения и ограничения.

Основная A/B-пара предназначена для сравнения одинакового Kotlin и вопроса без документации и с
RAG при одинаковых generation model/settings. Отдельный отрицательный сценарий
проверяет чужие правила и недоверенные инструкции. Использованы девять Markdown
snapshots Week 5; embeddings пересчитаны локально, исходная база не изменена.

## Что проверяет

- Находит ли поиск конкретные правила, включая общий вопрос с названием файла.
- Подтверждают ли источники объяснение и подходит ли правило текущему сценарию.
- Раздельность Knowledge/Workspace, актуальность и атомарность индекса,
  отсутствие скрытого fallback и сохранения пользовательского контекста.

## Результаты

Реализация и offline-проверки завершены. 10 октября 2026, Windows:
**222 offline tests passed, 1 skipped** (FIFO на Windows).
Локальная индексация и оба режима поиска работают. Vector нашёл русскую
перефразировку английского правила и все три правила checkout для общего вопроса;
text нашёл точный идентификатор, но пропустил часть правил. На Q01/Q07 Week 5
покрытие неполное; часть деталей вообще отсутствует в Markdown-подмножестве.
Непустые результаты Q10 не подтверждают знания об RPO/RTO.

Обе ветки исходного A/B завершились timeout без ответа (180,079 / 182,336 с)
на стадии загрузки/warm-up generation-модели. Отдельный diagnostic follow-up
с предварительной загрузкой дал технически успешный A (14,479 с), но preload B
завершился timeout (60,011 с), и B не запускался. Последний эксперимент с
`keep_alive=5m` остановился уже на начальном preload (60,009 с), до обоих ответов.
**Улучшение объяснения через RAG не подтверждено и не опровергнуто**:
смысловое A/B-сравнение не завершено. Все исторические результаты сохранены;
дальнейшие запуски прекращены. Нестабильность загрузки Ollama остаётся открытой
инфраструктурной проблемой, её причина не установлена.
Отрицательный прогон технически прошёл за 32,294 с; предварительный review ассистента —
**PARTIAL**: injection не выполнена, чужие правила не применены, но осталось
необоснованное утверждение о поведении зависимости. Human review ожидается.
Один прогон не доказывает общее превосходство RAG или устойчивость модели.
