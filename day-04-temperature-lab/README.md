# Day 04 — Влияние temperature

## Суть эксперимента

Сравнение ответов при temperature **0 / 0.7 / 1.2**. Модель получает один запрос:
придумать пять названий приложения для подготовки разработчиков к техническим
собеседованиям и короткие слоганы. Все остальные настройки одинаковы;
для наблюдения разнообразия запрос повторяется несколько раз.

## Что проверяет

Как temperature влияет на разнообразие названий и соблюдение требований:

- Ровно пять вариантов с неповторяющимися названиями.
- В названии 1–2 слова, без отдельных слов Interview, AI или ИИ.
- В слогане не больше восьми слов.

Автоматически проверяются требования и подсчитываются уникальные названия
для каждой temperature. Регистр и лишние пробелы не учитываются.
Уместность и креативность оценивает человек.

## Результаты

После **трёх прогонов** получено по 15 названий для каждой temperature:

| Temperature | Уникальных названий |
|---|---:|
| 0 | 6 из 15 |
| 0.7 | 13 из 15 |
| 1.2 | 13 из 15 |

В этих прогонах повышение temperature увеличило разнообразие, а при T=0
ответы не были полностью одинаковыми. Трёх прогонов недостаточно, чтобы
считать 0.7 и 1.2 эквивалентными. Разнообразие само по себе не означает
высокое качество названий или соблюдение требований.
