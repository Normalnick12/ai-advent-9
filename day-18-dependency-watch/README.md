# Day 18 — Планировщик и фоновые задачи

## Суть эксперимента

Агент через MCP создаёт наблюдение за версиями Android-библиотеки в Google Maven.
Сервис выполняет заданное число проверок по расписанию, сохраняет результаты
в SQLite и вычисляет сводку. Пользователь получает её отдельным запросом к агенту.

## Что проверяет

- Самостоятельное выполнение фоновых задач после завершения исходного запроса.
- Сохранение расписания и истории при перезапуске сервиса.
- Соответствие сводки и ответа модели фактическим результатам проверок.

## Результаты

В одном прогоне для `androidx.core:core-ktx` успешно выполнены все три проверки
с интервалом 30 секунд. Каждый снимок содержал 130 версий; изменений за период
наблюдения не обнаружено. Задача завершилась после заданного числа запусков.

Фоновые проверки выполнялись независимо от приложения и локального backend.
Сводка через MCP совпала с историей и рассчитанным итогом в SQLite, ответ модели
корректно передал эти факты. Отдельные проверки перезапуска сервиса и VPS
подтвердили сохранение наблюдений и истории.

Настройка и запуск описаны в [scripts](../scripts/README.md),
[backend](../backend/README.md) и [Android](../android-app/README.md).
`OPENAI_API_KEY` задаётся только на backend.
