## Why

Local Android Architecture Assistant уже объединяет локальную Ollama, Kotlin Workspace, Markdown Knowledge и проверяемые ссылки, но доступен только через CLI. Day 30 добавляет необязательный приватный HTTP-интерфейс с минимальным чатом и проверкой двух клиентов на Windows, сохраняя независимую локальную работу инструмента.

## What Changes

- Небольшая FastAPI-обвязка поверх общего runtime без копии RAG и нового агента; существующие CLI-команды сохраняют поведение и не требуют HTTP-зависимостей или работающего сервера.
- По умолчанию сервис слушает `127.0.0.1`; Ollama всегда доступна приложению только через `127.0.0.1`. Основная архитектура не использует VPS, публичный IP, router port forwarding или облачный inference.
- `POST /v1/chat`: разрешённый `file_id`, вопрос и клиентская история максимум из двух предыдущих пар и 8 KiB. Сервер не создаёт постоянных сессий; каждый ход использует текущий разрешённый Kotlin и актуальную Knowledge.
- Health/readiness, безопасный status, Bearer-аутентификация, ограничения тела/контекста, rate limit, два допускаемых одновременно запроса, ограниченные ожидания и безопасные ошибки. Очередь inference предоставляет Ollama; фактическая параллельная генерация не обязательна.
- Windows offline-проверки и отдельно разрешаемый ограниченный live: вопрос/уточнение, два клиента, контролируемые отказы. Для удалённой демонстрации основной кандидат — Tailscale Serve после отдельного подтверждения установки; Funnel только как отдельно разрешаемая временная публичная возможность.
- Отдельные технические и смысловые результаты. Coder 7B — только технический кандидат; итог Day 29 `NO SUITABLE PROFILE CONFIRMED` и исторические результаты Days 27–29 сохраняются.

## Capabilities

### New Capabilities

- `private-local-assistant-service`: необязательный защищённый HTTP-чат над существующим локальным архитектурным ассистентом, ограничение ресурсов, два клиента, приватная демонстрация и независимость CLI.

### Modified Capabilities

Нет. Контракты прежних CLI-команд и capabilities Weeks 1–5 не меняются; новая возможность описывается отдельной delta spec.

## Impact

- При Apply: каталог `day-30-private-assistant-service/` для HTTP-адаптера, минимального клиента, тестов и README; точечное выделение общей операции из `day-27-local-architecture-assistant/rag_cli.py` и обратно совместимые расширения общего runtime для истории/диагностики. RAG, path safety и response validation остаются едиными.
- FastAPI/Pydantic/Uvicorn устанавливаются отдельно и только для HTTP-режима. Общие CLI-зависимости не расширяются ими. SQLite Knowledge остаётся существующей read-only базой для обслуживания запросов, не хранилищем диалогов.
- При Apply: краткий Day README, относительная ссылка в корневом README и отдельные инструкции включения/отключения сервиса и сетевой демонстрации. Старый backend и Android-приложение не затрагиваются.
- Приёмка и демонстрация выполняются на Windows. Переносимость Python-кода на Mac M1 учитывается, но фактическая Mac-проверка — отдельный этап, не условие завершения Day 30.
- Вне объёма: MCP, новый агент, долговременная память, серверные сессии, новая vector DB, публичная инфраструктура по умолчанию, UI старого Android-приложения, автоматическая установка Tailscale/моделей, переоценка или архивирование предыдущих дней.
- Текущий этап создаёт только planning artifacts; Apply, inference, сетевые настройки, commit/push, archive и видео не выполняются.
