## Why

Android-разработчику нужен простой локальный способ получить объяснение незнакомого Kotlin-класса без передачи исходников облачной LLM. Day 27 начинает самостоятельную переносимую утилиту для Windows и будущего использования на Mac M1 с 16 GB RAM, ограничивая первый эксперимент одним явно выбранным файлом.

## What Changes

- Добавить независимый Python CLI в `day-27-local-architecture-assistant/`: Workspace, относительный путь Kotlin-файла, вопрос, модель и loopback URL Ollama. Если вопрос не указан, прочитать его один раз из терминала.
- Безопасно прочитать один ограниченный UTF-8 файл, собрать ограниченный контекст и выполнить один синхронный HTTP-запрос без proxy, redirects и автоматических повторов.
- Явно задавать `num_ctx=8192` и ограниченный `num_predict`; после metadata `/api/show` отключать поддерживаемый thinking через `think:false`, распознавать незавершённую генерацию. Проверять local-only режим самого сервера перед live, не управляя им из CLI. Наблюдение пользователя из Day 26 о переполнении окна 4096 учитывается как исходное ограничение, а не новый проверенный результат Day 27.
- Разделять ответ на facts с номерами строк, assumptions и limitations; механическая проверка ссылок не заменяет ручную оценку смысла.
- Не сохранять исходники, вопросы, ответы или историю; использовать только синтетические тестовые данные и отделённый от кода Workspace.
- Проверить ограничения offline с подставным HTTP transport и выполнить один live-запуск на Windows через Ollama 0.40.2 и `qwen3.5:9b-q4_K_M`, сохранив только разрешённые неперсональные метрики и краткие наблюдения.
- Обновить краткий Day README и относительную ссылку в корневом README при реализации.

За рамками: FastAPI/backend integration, Android UI, рефакторинг общего LlmClient/агента, MCP, Docker, обход зависимостей, несколько файлов, чат, Knowledge/RAG (Day 28), оптимизация моделей (Day 29), HTTP-сервис и несколько клиентов (Day 30). Видео сейчас не требуется.

## Capabilities

### New Capabilities

- `local-architecture-assistant`: однофайловое локальное объяснение Kotlin-кода с ограниченным доступом к Workspace, управлением HTTP/контекстом, проверяемой структурой ответа и приватной диагностикой.

### Modified Capabilities

Нет. Контракты предыдущих дней сохраняются.

## Impact

Новый самостоятельный каталог дня, его синтетические fixtures, offline-тесты и документация; ссылка в корневом README. Runtime: Python 3.12+ и `httpx`; development: `pytest`. Python 3.12 выбран для штатной проверки Windows junctions. Существующие backend, Android, зависимости и dev.ps1 не изменяются. Переиспользуются подходы к проверке путей, подмене клиента и grounding, без runtime-импортов из backend. Локальные данные остаются вне Git либо в уже игнорируемой `.local/`.
