# Day 27 — Local Android Architecture Assistant

## Суть эксперимента

Самостоятельный Python CLI объясняет один Kotlin-файл из разрешённого каталога
через локальную Ollama. Ответ разделён на факты со ссылками на строки,
предположения и ограничения. Исходник, вопросы и ответы приложение не сохраняет.

## Что проверяет

- Объяснение роли класса, зависимостей и видимых вызовов.
- Ограничение доступа выбранным файлом.
- Разделение проверки структуры ответа и оценки его смысла.

## Результаты

На Windows получено объяснение синтетического CheckoutCoordinator. Ответ прошёл
проверку структуры и номеров строк. Ручная оценка — **частично полезно (PARTIAL)**:
основные действия описаны, но есть неподтверждённые предположения о зависимостях
и неполное объяснение навигации.

Запуск на Mac не проверялся. Зависимости, настройка и команды описаны
в [руководстве CLI](docs/usage.md#запуск).
