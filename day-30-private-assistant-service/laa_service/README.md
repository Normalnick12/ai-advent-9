# HTTP-компонент Local Android Architecture Assistant

Необязательный FastAPI-адаптер использует общий runtime помощника.
CLI, Knowledge и локальная Ollama работают без запуска HTTP-сервиса.

- [Установка, конфигурация, клиент и HTTP-контракт](../docs/http-service.md)
- [Описание эксперимента и результаты Day 30](../README.md)

Сервис по умолчанию слушает только loopback. Для доступа нужны токен и
заранее разрешённые владельцем файлы; произвольные пути клиент не передаёт.
