# Day 17 — Первый MCP-инструмент

## Суть эксперимента

Агент в Android-приложении получает сведения о версиях библиотеки через собственный
MCP-сервер. Инструмент обращается к Google Maven и возвращает данные для ответа.
В эксперименте агенту нужно назвать количество версий и три последних элемента списка.

## Что проверяет

- Собственный MCP-инструмент принимает параметры и возвращает результат.
- Агент вызывает инструмент из приложения и использует полученные данные в ответе.
- Ответ модели соответствует результату инструмента.

## Результаты

В одной попытке агент вызвал инструмент для `androidx.core:core-ktx` и получил
129 версий. Три последних элемента он указал правильно, но в количестве ошибся —
назвал 133. Вызов MCP подтверждён, однако проверка точности ответа не пройдена.

Инструмент был выбран заранее. Режим самостоятельного выбора не проверялся;
повторов и исправления ответа не было. Этот пример показывает, что успешный
вызов инструмента сам по себе не гарантирует правильный ответ модели.
