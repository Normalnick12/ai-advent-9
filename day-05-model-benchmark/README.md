# Day 05 — Model Benchmark Lab

«Лаборатория моделей» сравнивает три модели на пяти фиксированных задачах:
арифметика, расписание, выбор набора функций, трассировка алгоритма и подсчёт строк.
Backend независимо проверяет ответы; Android показывает качество, время,
фактические токены, стоимость и детали каждой задачи.

## Запуск

Нужны Python 3.11+, зависимости backend, Android Studio/SDK, JDK 17+,
Android Emulator и PowerShell 7. Подготовка:
[backend](../backend/README.md), [Android](../android-app/README.md).
Единственная необходимая переменная — `OPENAI_API_KEY` в локальном
`backend/.env` или окружении backend. Android не получает ключ.

Из корня проекта в PowerShell 7:

```powershell
.\scripts\dev.ps1 backend
```

Оставьте сервер в этом терминале. В другом выполните
`.\scripts\dev.ps1 status` и `.\scripts\dev.ps1 emulator`, затем запустите
`app` из Android Studio. Откройте Day 05 и нажмите «Запустить сравнение».
Каталог моделей сам по себе не вызывает OpenAI.

## Эксперимент

Начальные слоты: экономичная Luna, сбалансированная Terra, флагманская Sol.
Доступные модели задаёт backend; одинаковую модель можно выбрать в нескольких
слотах — это отдельные вызовы. Каждый запуск делает три параллельных Responses
API call с одинаковыми prompt, instructions и strict JSON schema.
Меняется только model: `gpt-5.6-luna`, `gpt-5.6-terra` или `gpt-5.6-sol`.
Параметры: `reasoning.effort=medium`, `max_output_tokens=6000`,
temperature/top_p omitted, без retries. Все условия и задачи видны на экране.

Качество считается только для завершённого структурно корректного ответа.
Incomplete, отказ, ошибка и непроверяемый output обозначаются отдельно;
они не превращаются в 0/5. Стоимость рассчитана по фактическому usage и
сохранённым тарифам, не по лимиту токенов; при недостатке данных она неизвестна.
Reasoning уже входит в output. Детали показывают источник и дату тарифов.

## Предварительные одноразовые probes

| Probe | Условия | Luna | Terra | Sol |
| --- | --- | --- | --- | --- |
| 1 | Простые Task 4/5, лимит 3000 | 5/5 | 5/5 | 5/5 |
| 2 | Текущие Task 4/5, лимит 3000 | Incomplete, нет проверяемого результата | 5/5 | 5/5 |
| 3 | Те же задачи, лимит 6000 | 4/5, Task 5: 21 вместо 24 | 5/5 | 5/5 |

В третьем probe время составило 86,044 / 57,488 / 92,996 с,
стоимость — 0,0071506 / 0,040486 / 0,114032 USD соответственно.
Это три исторических наблюдения, а не статистически устойчивый рейтинг;
новый запуск не обязан их повторять. Подходящую модель выбирают по качеству
на конкретной задаче, допустимой задержке и бюджету.

Результат последнего запуска и выбор моделей сохраняются при переходах между
днями и повороте экрана в текущей сессии. Постоянной истории нет.
Проверки проекта и управление окружением: [scripts](../scripts/README.md).
