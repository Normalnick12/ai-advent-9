# Day 32 — Автоматизация ревью кода

## Суть эксперимента

GitHub Actions автоматически проверяет Pull Request: получает настоящий diff,
находит контекст в документации и исходном коде и запрашивает структурированное
ревью OpenAI. Один комментарий PR обновляется после нового коммита.

## Что проверяет

- RAG отдельно по пяти документам Day 31 и изменённому коду с очевидными тестами.
- Замечания с проверяемыми основаниями, изменёнными строками и revision источников.
- Доверенный ревьюер из `main`, который обрабатывает содержимое PR только как данные.
- Повторное ревью исправленного SHA и защита от запоздавшей публикации старого результата.

## Результаты

Целевой offline-прогон: 164 теста PASS, включая 79 проверок Day 32.
После исправления демонстрационных дефектов отдельно прошёл пересекающийся
набор из 41 теста; эти количества не складываются.

В [демонстрационном PR #1](https://github.com/Normalnick12/ai-advent-9/pull/1)
проведены два настоящих автоматических ревью.
[Первое](https://github.com/Normalnick12/ai-advent-9/actions/runs/38954367391)
обнаружило оба заданных дефекта: обратную сортировку cosine similarity и
отключение проверки свежести индекса. Объяснение первого корректно; объяснение
второго — PARTIAL: модель не полностью учла отдельную проверку в `read()`.
[Второе](https://github.com/Normalnick12/ai-advent-9/actions/runs/38956152557)
после исправлений обновило тот же комментарий без дубликата и вернуло ноль
замечаний по оставшемуся безвредному diff.

Два запуска подтверждают работу автоматизации в этом сценарии, но не универсальную
точность ревьюера. Охват ограничен diff и выбранными источниками; исправленный
файл, исчезнувший из diff, не проходит отдельную повторную LLM-проверку.
Отсутствие замечаний не доказывает отсутствие ошибок. Пользователь подтвердил
запись немого скринкаста; видео хранится отдельно от Git.

Зависимости и ограничения описаны в [backend](../backend/README.md),
команды и настройка GitHub Environment — в [scripts](../scripts/README.md).
`OPENAI_API_KEY` используется только Python-ревьюером; в Actions хранится
в Environment `day32-review`, доступном запуску из `main`.
